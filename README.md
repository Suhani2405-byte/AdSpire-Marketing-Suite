# 🚀 Adspire — Autonomous Multi-Channel Marketing Suite

> An autonomous multi-channel marketing campaign architecture and predictive ROAS budgeting platform featuring live social mockups, buyer persona profiling, and generative creative asset synthesis.

---

## 🌟 Key Features

1. **🚀 Campaign Studio**:
   - Multi-channel marketing deliverable generation.
   - Target buyer persona profiler, psychographic desires, and objection busters.
   - Primary ad copy + A/B testing variants with conversion hypotheses.
   - Social posts: Instagram captions with hashtags, LinkedIn thought leadership, viral TikTok/Reels video scripts.
   - Email marketing suite with open-rate optimized subject line alternatives.
   - 7-day omnichannel launch roadmap.

2. **📱 Live Interactive Mockups**:
   - 📸 **Instagram Feed Ad**: Simulated mobile card with interactive Like ❤️ and Bookmark 🔖 buttons, sponsored tags, CTA bars.
   - 🎵 **TikTok Video Reel**: 9:16 vertical video player UI with engagement counters and audio sound tags.
   - 💼 **LinkedIn Sponsored Post**: Enterprise branding and sponsored post card.
   - 🔍 **Google Search Ad**: Google SERP snippet with sitelinks and URL breadcrumbs.

3. **🎨 Creative Visual Studio**:
   - High-resolution advertising image synthesis (FLUX.1).
   - Style presets: *Photorealistic, 3D Render, Cyberpunk, Minimalist, Luxury, Vibrant Pop*.
   - Aspect ratio selection (1:1, 16:9, 9:16) with one-click PNG download.

4. **💰 Predictive Budget & ROAS Simulator**:
   - Real-time sliders for spend and duration.
   - Channel breakdown table with CPC, CTR, Impressions, CPA, Net Profit, and ROAS calculations.

5. **📁 Persistent Campaign Hub**:
   - SQLite database for storing, reviewing, reloading, and exporting campaigns.

---

## ⚡ Quick Start

### 1. Launch with One Click (Windows)
Double-click `run.bat` in the root folder.

### 2. Cross-Platform / Manual Start
```bash
# Start backend and serve frontend
python start.py
```

### 3. Open in Browser
- Local: [http://127.0.0.1:5000](http://127.0.0.1:5000) or [http://localhost:5000](http://localhost:5000)
- Mobile on same Wi-Fi: `http://<your-local-ip>:5000`
